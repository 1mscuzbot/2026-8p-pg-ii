## Cronograma PG-II (2026/2)

| Prazo | Etapa | Documento |
|-------|-------|-----------|
| 22/08 (4ª semana) | Entrega da proposta do PG atualizada | Proposta do PG I com atualizações (cronograma atualizado) |
| 22/08 (4ª semana) | Entrega do PG corrigido | PG I com as correções solicitadas pelos professores na Avaliação |
| 10/10 (11ª semana) | Entrega do PG II (checkpoint) | PG + procedimentos metodológicos, ferramentas, código-fonte, descrição de estruturas/algoritmos |
| 12ª semana | Retorno do checkpoint | Devolvido com correções (sem nota) |
| 14/11 (16ª semana) | Entrega para banca do PG II | Texto monográfico completo (pré-textuais, introdução, fundamentação, metodologia, ferramentas, resultados e discussões, conclusões, pós-textuais) + programa implementado — formatado ABNT/UTP |
| 30/11 a 05/12 (Semana de 2ª chamada) | **Banca do PG II** | Apresentação oral (15-20 min) + arguição (10-20 min). Avaliação pelo Apêndice CC3 |
| 7 dias após a banca | Entrega para re-banca | Mesma documentação corrigida (somente para notas entre 4,0 e 6,9) |
| Caso a caso | Re-banca | Até 7 dias corridos após a banca: texto em PDF + programa + autorização de publicação (Apêndice CC4) |

## Observações

- Entregas e retirada de trabalhos corrigidos pelo **OneDrive**
